# CSCI426 Project Phase 1 - Smart Health Guardian

## Overview
Smart Health Guardian is a responsive ReactJS frontend web application built as part of **Phase 1** for the **CSCI426: Advanced Web Programming** course. It provides an intuitive platform for preventive health monitoring, daily metric tracking (BMI, water intake, sleep cycles), symptom evaluation, and medication management.

## Key Features & Pages
1. **Home / Dashboard**: Features an interactive BMI calculator and real-time metric trackers (Sleep & Water intake).
2. **Symptom Checker (Dynamic Page)**: Rule-based health evaluations providing initial non-diagnostic advice based on symptom severity and duration.
3. **Medication Tracker**: Interactive checklist allowing users to add, schedule, and mark daily medication doses as completed.
4. **Services**: Overview of preventive features and tools available on the platform.
5. **Contact**: User inquiry form for support or health queries.

## Technologies Used
- **Frontend Framework**: ReactJS (Functional Components & Hooks)
- **Routing**: `react-router-dom` v6
- **Styling**: CSS3 (Flexbox & CSS Grid for full responsive design across desktop and mobile screens)
- **Version Control**: Git & GitHub
